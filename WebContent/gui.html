Report Definition
Response Rates Report This option allows the user to calculate response rates for a requested period and login date and time.
Weekly Analysis Report This option allows the user to calculate response rates on a weekly basis for REST and the Repricing BPT. It provides response rates for the current month and the period twelve months prior for the same number of days after mailout. This report can be run for t (repricing current processing period), t-1, t-2, or t+1 (if data exists).
Calculate Monthly Data This job is used to calculate monthly export, import, or aggregate response rates for periods T (preliminary) or T-3 (final) after indexes are finalized. This data is used as an input for the ProdQual, BLS and OMB measures.
Monthly Response Data This option allows the user to view monthly preliminary or final export, import, or aggregate response rate data. This data is used in ProdQual, BLS and OMB measures.
Weighted Estimation Response This option allows the users to view the actual index calculation weighted response rates.
Form for entering report arguments:









"Actual Data" - number of responses
"Percentage" - the response rate

"Trade" � trade type (i.e. Imports vs. Exports)
"Assign Mode" � assigned mode of collection (e.g. Web, Mail-Out/Fax-Back, etc.)
"Requested" � requested ("Y") or pulled ("P")

"Prelim" - indexes were finalized for their first release
"Final" - indexes were finalized for the fourth and final time
